This repository ships three kinds of material under three different terms.
`LICENSE` carries the code grant; this file is the full statement.

| Layer | What it covers | Terms |

| **Code** | The source code in every `.html`, `.js`, `.py` file: the arenas, their deterministic cores and Python twins, the build script — **excluding** the embedded course content and brand tables covered in the two rows below | **MIT** — see `LICENSE` |

## Brand assets — the reserved layer

The Plarena name, logotype and robot mascot are trademarks / brand assets of
Xian Su. They are **not** part of the MIT grant.

You may run the apps, study them, fork the code, and ship your own teaching
tools built on it. You may **not** use the Plarena name or the mascot to brand
a derivative product, merchandise, or service without written permission.

If you fork this repository for your own suite, replace the name and the
`MASCOT` / `ICONS` tables with your own — the code works without them.

## Course content — the CC BY layer

The teaching material is meant to be taken and used. Put Map-1 in your slides,
reuse a room's narration, cite a certified number in a paper — all fine, just
attribute it. Suggested form:

> Map-1 and the accompanying certified figures are from Plarena (Xian Su,
> Florida International University), CC BY 4.0

If you use Plarena in teaching or research, `CITATION.cff` has the full
citation, and GitHub's "Cite this repository" button renders it for you.

## Why the split

The code is meant to be forked; the content is meant to be taught with; the
name and the mascot are how people know this suite is this suite. Only the
last one needs to stay closed.

*Commercial use of the brand assets requires a formal trademark search first —
this notice is a statement of intent, not legal advice.*
